# หารมื้อ (Bill Splitter)

เว็บแอปหน้าเดียวสำหรับคำนวณและหารบิลค่าอาหาร รองรับส่วนลด Service Charge และ VAT 7% แบบไทย
พร้อมกระจายเศษสตางค์ให้ยอดรวมของทุกคนตรงกับยอดบิลจริง 100%

- **Prompt Log:** https://docs.google.com/document/d/1alrATp7ki94-mhbq6GMDUushgq60u0iPjbYXveHJaLo/edit

## ทำอะไรได้บ้าง

- กรอกยอดบิลเองหรือให้รวมจากรายการอาหารอัตโนมัติ
- ตั้งส่วนลด / Service Charge / VAT ได้ทั้งแบบเปอร์เซ็นต์และจำนวนเงินคงที่ และเลือกได้ว่าจะคิด VAT ทับ Service Charge หรือไม่
- จัดการผู้ร่วมหาร เพิ่ม ลบ แก้ชื่อ หรือกดพรีเซ็ตจำนวนคน
- หารได้ 3 โหมด คือ หารเท่ากัน เลือกตามรายการที่แต่ละคนกิน และกำหนดยอด/สัดส่วนเอง
- สร้าง QR พร้อมเพย์ในเครื่องเพื่อให้เพื่อนโอนตามยอดที่คำนวณได้
- คำนวณใหม่ทันทีทุกครั้งที่แก้ข้อมูล และใช้งานได้บนจอมือถือ

## วิธีใช้

1. กรอกยอดบิลและตั้งค่าภาษี/ค่าบริการในส่วนที่ 1
2. ใส่ชื่อคนที่ร่วมหารในส่วนที่ 2
3. เลือกรูปแบบการหารในส่วนที่ 3
4. ดูยอดที่แต่ละคนต้องจ่ายในส่วนที่ 4 แล้วกดเปิด QR พร้อมเพย์ได้เลย

ปุ่มบนหัวเว็บใช้โหลดตัวอย่างมื้อร้านอาหารเพื่อลองเล่น และล้างข้อมูลทั้งหมดเพื่อเริ่มบิลใหม่

## เทคโนโลยีที่ใช้

React 19, TypeScript, Vite, Tailwind CSS, lucide-react, motion และไลบรารี qrcode
ตรรกะการคำนวณทั้งหมดอยู่ใน `src/utils/calculator.ts` ส่วนการสร้าง payload พร้อมเพย์ตามมาตรฐาน EMVCo อยู่ใน `src/utils/promptpay.ts`

แอปทำงานฝั่งเบราว์เซอร์ล้วน ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล ไม่มีระบบล็อกอิน และไม่เรียก API ภายนอกใด ๆ จึงไม่ต้องใช้ API key

## รันในเครื่อง

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## โครงสร้างโปรเจกต์

```
src/
  App.tsx           สถานะกลางของบิลและการประกอบหน้าจอ
  types.ts          ชนิดข้อมูลของบิล คน และผลลัพธ์
  components/       ส่วนติดต่อผู้ใช้แต่ละบล็อก
  utils/            ตรรกะคำนวณบิลและสร้าง QR พร้อมเพย์
```
